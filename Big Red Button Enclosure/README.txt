Big Red Button Enclosure by alpenglow on Thingiverse: https://www.thingiverse.com/thing:4373592

Summary:
Big red arcade buttons are great additions to any project, but they need an enclosure to be able to stand up on their own.  This one has been designed specifically for 60mm buttons, with enough internal space for a wire harness that uses right angle quick connects, and has an integrated strain relief clip as well as hole for a 5/16" grommet (McMaster-Carr part number 9600K13).  The main enclosure body has been specifically designed for 3D printing, so can be printed upside-down, with no support material.The lid can also be printed without supports, right-side up.  It takes 3 flat-head 4-20 x 1/2" long thread-rolling screws (Amazon/Small Parts ASIN: B00GDXSZQ4) to fasten it to the enclosure body..x3g files are set up for a Flashforge Creator Pro.We've also included files for a custom nut driver tool, so you can easily screw the button into the enclosure.  Two nut shapes are included - a rounded hex type and a sharper hex type.  They are also - you guessed it - able to be printed without support structure.
